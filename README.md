## Featured Projects

### 🏥 InstaCare — Healthcare Management Platform *(Production)*
> React.js · TypeScript · Leaflet.js · Razorpay SDK · CSS Animations

Built the **entire frontend** for a 3-portal healthcare platform serving patients, admins, and doctors.

- **25+ screens** across Patient Portal, Admin Dashboard, and Doctor Portal
- **5-step booking flow**: Specialisation → Doctor → Branch (Leaflet map with live GPS) → Slot calendar → Razorpay payment
- Slot calendar with colour-coded availability + real-time past-time filtering
- Razorpay 2-phase payment — 0 payment-slot desyncs in production
- Lazy loading + React.memo: render time ~800ms → ~120ms on 50+ cards
- Complete API error handling (400/401/403/404/409/500) with skeleton loaders + retry logic
- Prescription module with S3 URL validation and appointment-grouped PDF viewer
